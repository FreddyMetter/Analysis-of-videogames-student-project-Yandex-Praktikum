# 🎮 Исследование продаж и оценок видеоигр (2000–2013 гг.)

**Учебный проект** в рамках курса Яндекс Практикума, изучение библиотеки Pandas.  
**Автор:** Суздалов Дмитрий

---

## 🎯 Цель проекта

Подготовить корректный срез данных о видеоиграх за **2000–2013 гг.** и провести его первичный анализ:

- проверить качество данных;
- выполнить предобработку;
- отфильтровать нужный период;
- категоризировать игры по оценкам пользователей и критиков;
- определить **топ-7 платформ** по количеству выпущенных игр.

---

## 📦 Данные

Исходный датасет `new_games.csv` содержит:

- название игры;
- платформу;
- год выпуска;
- жанр;
- продажи по регионам: **NA, EU, JP, Other**;
- оценки критиков и пользователей;
- рейтинг ESRB.

---

## 🛠 Что было сделано

### 1. Загрузка и знакомство с данными
- изучена структура датафрейма;
- проверены типы данных;
- найдены пропуски и дубликаты.

### 2. Предобработка
- названия столбцов приведены к стилю **`snake_case`**;
- исправлены типы данных для числовых столбцов и оценок;
- обработаны значения `unknown` и `tbd`;
- удалены полные и частичные дубликаты;
- текстовые значения приведены к единому регистру.

### 3. Фильтрация
- отобраны игры за период **с 2000 по 2013 год включительно**;
- результат сохранён в отдельный датафрейм **`df_actual`**.

### 4. Категоризация
Добавлены новые признаки:

- **`user_game_score_category`** — категория по оценке пользователей;
- **`critics_game_score_category`** — категория по оценке критиков.

Категории:
- **высокая оценка**;
- **средняя оценка**;
- **низкая оценка**;
- **нет оценки**.

---

## 📊 Ключевые результаты

- В ходе очистки удалено **257 строк** — это **1,52%** исходных данных.
- Итоговый срез: **12 769 игр** за 2000–2013 гг.
- Добавлены две новые категориальные колонки с оценками.

### Распределение по оценкам пользователей
- **нет оценки** — 6 296;
- **средняя оценка** — 4 077;
- **высокая оценка** — 2 280;
- **низкая оценка** — 116.

### Распределение по оценкам критиков
- **нет оценки** — 5 610;
- **средняя оценка** — 5 421;
- **высокая оценка** — 1 683;
- **низкая оценка** — 55.

### Топ-7 платформ за период
1. **PS2**
2. **DS**
3. **Wii**
4. **PSP**
5. **X360**
6. **PS3**
7. **GBA**

В проекте выполнена комплексная предобработка данных:
