Исследование продаж и оценок видеоигр (2000–2013 гг.)
Учебный проект по анализу данных, выполненный в рамках курса Яндекс Практикума.
Автор: Суздалов Дмитрий

## 🎯 Цель проекта
Подготовить и проанализировать срез данных о видеоиграх за период с 2000 по 2013 год: проверить корректность данных, выполнить предобработку, отфильтровать нужный период, категоризировать игры по оценкам пользователей и критиков, а также определить топ-7 платформ по количеству выпущенных игр.

## 📊 Данные
Исходный датасет new_games.csv содержит информацию о продажах игр по регионам (NA, EU, JP, Other), жанрах, платформах, годе выпуска, оценках критиков и пользователей, а также рейтинге ESRB.

## 🛠 Этапы работы
Загрузка и знакомство с данными — изучение структуры, типов данных, пропусков.

Предобработка:

- ##приведение названий столбцов к snake_case;

- ##исправление типов данных (числовые столбцы, оценки);

- ##обработка пропусков и неявных дубликатов (unknown, tbd, регистр);

- ##удаление полных и частичных дубликатов.

- ##Фильтрация — отбор игр, выпущенных с 2000 по 2013 год включительно (итоговый датафрейм df_actual, 12 769 строк).

Категоризация:

- ##по оценкам пользователей (user_score): высокая (8–10), средняя (3–8), низкая (0–3);

- ##по оценкам критиков (critic_score): высокая (80–100), средняя (30–80), низкая (0–30).

Анализ — подсчёт количества игр в каждой категории и определение топ-7 платформ.
